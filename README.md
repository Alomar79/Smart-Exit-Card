
# Smart Exit Card

A school web application for recording student departures
and returns using QR codes.

## Key Features
- Record student departures and returns.
- Display students currently outside the classroom.
- Provide a supervisor dashboard and usage statistics.
- Organize records by class and destination.

## Technologies
Google Apps Script, Google Sheets, HTML, CSS and JavaScript.

## My Role
Designed and developed the system to support daily school
operations across 41 class groups.


## الشرح بالعربية

### بطاقة الخروج الذكية
تطبيق مدرسي لتسجيل خروج الطلبة من الصف وعودتهم
باستخدام رموز QR، بهدف تنظيم الاستئذان وتسهيل المتابعة.

### المميزات
- تسجيل خروج الطلبة وعودتهم.
- عرض الطلبة الموجودين خارج الصف حاليًا.
- توفير لوحة للمشرفة وإحصائيات الاستخدام.
- تنظيم السجلات حسب الصف والوجهة.

### التقنيات المستخدمة
Google Apps Script، Google Sheets، HTML، CSS، JavaScript.

### دوري في المشروع
صممت وطورت النظام لدعم العمل المدرسي اليومي،
ليخدم 41 شعبة دراسية في الفترتين الصباحية والمسائية.
